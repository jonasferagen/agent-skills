# A small shared plan

This synthetic example coordinates two owners. The plan owns these items;
existing local tasks could instead own their status and be linked here.

Outcome: open one exported document in a fresh viewer session. Source selection
and a local import are in scope. A general catalog is deferred until several
consumers need independent selection histories.

## Source inventory

Owner: Viewer. Status: Ready.

Result and evidence: identify the selected source and relevant helpers, retaining
their revisions and a mapping to the intended homes. Inputs are available.
Next action: inspect the retained source and record the selection.

## Sample export

Owner: Producer. Status: Blocked on output requirements.

Result and evidence: one candidate document with input identity and an output
record. Next action: obtain the required output behavior from the requesting
owner. A successful export alone does not establish suitability for import.

## Fresh-session import

Owner: Viewer. Status: Waiting on source selection and a reviewed sample.

Result and evidence: the selected output opens in a fresh session and a local
adaptation survives an update. Next action: review the candidate against the
import requirements once it is available; then exercise the import.

The inventory can proceed while export requirements remain unresolved. If it
finds an incompatible helper, retain the useful mapping as partial evidence and
make compatibility checking its next action. Only dependent startup work waits.
Keep the dated finding in the project's work record and update this active item;
do not leave both old and new next actions in circulation.
