# Flowcharts

Use a flowchart for work steps and the conditions that select what happens next.
A component map drawn with Mermaid's `flowchart` syntax still needs component
semantics; syntax alone does not make it a workflow.

- Read, explain or apply a view: [reading notes](read.md).
- Review accuracy: [semantic review](../review.md) with the reading notes.
- Create or change source: [construction](design.md).
- Review rendered readability only: [verification](../verification.md).

Use [form selection](../select.md) when the question concerns one object's states,
ordered participant interactions, data movement or component relationships.
[Mermaid's official documentation](https://mermaid.js.org/syntax/flowchart.html)
owns renderer syntax. The minimal notation below is this skill's convention,
subject to an existing view's declared legend; it is not a claim of formal BPMN
or UML compliance.
