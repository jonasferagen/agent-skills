# Entity-relationship diagrams

Route by the task; the model or schema owns meanings and constraints, while this
family owns their representation.

- Read, explain or apply an existing ER: [reading notes](read.md).
- Review its accuracy: [semantic review](../review.md) with the reading notes.
- Create or change an ER: [construction](design.md), which routes to notation,
  visual checks and large-model guidance only as needed.
- Review only rendered readability: [verification](../verification.md).

A large existing view does not require decomposition merely to answer a focused
reading question. Examples and layout rules belong to construction work.
