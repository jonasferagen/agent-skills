### Item trace

In the retained synthetic example, source inventory needs only the retained source
and can proceed. Sample export needs output requirements; producing bytes is not
proof of import suitability. Fresh-session import requires the source selection
and a reviewed sample, then observes both opening and update survival. The next
action is review when a candidate is available; until then the missing input is
explicit. A general catalog returns only when several consumers need independent
selection histories. These statements distinguish a real dependency, partial
success and a deferred choice without serializing every owner.

For a local brief already coordinating sample export, replace the plan's copied
status and next action with a link to that brief. The plan can retain the required
result and its relationship to import. This is one coordination owner at each
scope, not two competing queues for the same action.
