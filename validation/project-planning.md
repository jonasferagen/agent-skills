# Project planning validation

## Scope and cases

Project planning owns bounded outcomes, dependencies, one status owner per item,
plan maintenance and deferral. Architecture and execution remain separate.
Canonical managed homes are governed by the collection document map.

- A blocked export does not block an independent source inventory.
- Successful export leaves review and consumer-adoption dependencies open.
- Shared plans link local technical detail without creating competing queues.
- Existing layouts remain until deliberate migration; new managed documents use
  the reserved directory. Routine status reading does not migrate files.
- A literal wording correction needs no full replanning pass.
- Plans do not authorize paid execution or source migration.

## Trial — 2026-10-03

A fresh agent entered a synthetic consumer through AGENTS and the installed
collection, with an existing planning owner and a repository handoff diagram.
It reviewed next steps without editing project files. The response identified
stale export status, independent inventory, outstanding review and source-selection
requirements, and deferred paid conversion. It preserved the existing planning
home and interpreted the diagram as responsibilities rather than execution order.
The fixture had no foundation; the response explicitly retained that limitation.

The recorded read log counted approximately 5,041 words across 12 files, without
truncation or repeated content reads. Foundation-format was unnecessary with no
foundation present; multi-repository setup detail was broader than this task.
No source maintenance material or renderer guidance was loaded. This demonstrates
one route, not reliable automatic client discovery. A literal wording-only case
was author-reviewed, not independently executed.

The trial preceded the final closed-set layout wording and structural checker.
Those additions were checked separately through ten helper tests, including
allowed minimal content, missing plan indexes, unrecognized categories, nested
output and external symlinks. Structural validation does not establish semantic
placement. Forge supplies the real multi-repository migration check.

Clear-writing guidance kept optional planning fields distinct from fixed document
homes. Pattern capture supported moving next-step selection into the planning
owner while retaining the old link as a route. Python-patterns informed the layout
checker's distinction between a missing directory and an allowed minimal layout.
