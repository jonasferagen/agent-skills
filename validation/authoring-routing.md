# Authoring routing trials — 2 October 2026

## Scope and changes

The [ER follow-up](er-routing.md) found that a short factual answer and literal
README edit still loaded authoring and visual-selection guidance. Two bounded
rounds address that route and the repository's own source-authoring route.

Round 1 changes the collection entrypoint and shared authoring reference. Reading
an existing owner and making an exact, meaning-preserving edit need no authoring
workflow. Composing explanations still reaches writing guidance, and relationships,
sequences and comparable cases still reach visual selection. A small edit that
changes a decision or obligation follows its governing workflow.

Round 2 changes source AGENTS and the README authoring principle. A known skill
is the starting point for a focused source edit. Links route maintenance work to
relevant README sections; applicable behavior cases and historical trial records
have distinct reading conditions. Writing, package checks and scenario review
remain required where relevant.

No skills, tools or installation units were added. These are shared collection
and source-maintenance changes, identified by the source commit. Skill manifests
and installed copies in real Atlas were not updated.

## Method

Five fresh agents worked in isolated tracked fixtures under
`/tmp/authoring-routing-88c16pg5`. Consumer copies used source base `39e54fb` plus
the round-1 edits; source fixtures added the corresponding maintenance changes.
Agents entered through project or source AGENTS and received the task, not the
expected reading route or prior findings. No network, installations, runtime or
real-project edits were permitted. Counts are agent-reported whitespace words,
separating project inputs and output review from guidance. They are not token or
whole-context measurements.

## Round 1: consumer tasks

### Existing model question and literal edit

The task matched the previous trial: answer whether agreements can cover several
services and whether an organisation's roles can differ by service, then replace
only “No implementation exists.” with “Nothing is implemented yet.” in README.

The answer preserved the conceptual/provisional status, role scope and unresolved
counts, absence, identity and lifecycle. The [patch](authoring-routing/lookup.patch)
contains the exact sentence change alone; full-text comparison passed.

Guidance reads were AGENTS, relational-modeling, COLLECTION and foundation
authority: **1,524 words**, versus **3,224** in the prior run. Project input was
770 words; output review was 60 words. No authoring, clear-writing, visual or
friction reference was loaded. The earlier run's friction read followed a missing
`python` alias, which did not recur here; the entire reduction cannot be attributed
solely to routing. The concrete result is that the unnecessary authoring chain
was avoided while meaning and scope were preserved.

### Compose a comparison

The agent received [planning notes](authoring-routing/comparison-notes.md) for
three ways to exercise retrieval, with shared comparison criteria and no requested
visual form. It produced a [comparison document](authoring-routing/comparison.patch)
using a table and a bounded recommendation. All supplied options and criteria
remain visible. It distinguished assumptions from measured results, linked open
model decisions and adopted no stack or implementation.

It read clear-writing, visual selection and tables, alongside the collection,
shared authoring, authority and project instructions: **2,734 guidance words**.
Project input was 871 words; output review was 354. It loaded no diagram
construction or rendering guidance. Only the requested document was created;
source/link/whitespace review passed. The table's rendered width was not tested.

### Literal replacement that changes policy

The task changed the policy's Allowed environment from “Local only.” to “Local or
hosted.” as the owner's adopted direction. The [result](authoring-routing/policy.patch)
updated the value and revision, reconciled the stale environment statement in
AGENTS and added a compact hosting transition review. Actual environment remained
local documents with no deployment. Synthetic-only data and read-only scope were
preserved. Hosted readiness stayed open.

The agent reached project-policy, policy changes, source-of-truth, definitions,
authoring, clear-writing and instruction guidance. It read **5,999 guidance words**
and 1,492 project-input words. It identified full model/scenario reads (1,173
words) and runtime material in the definitions reference as unnecessary detail.
Final artifacts contain 488 words; draft/diff/repeated output review totaled
approximately 1,700 displayed words. Changed-file links and whitespace passed.

The parent gave a scope reminder during this run; the agent then shortened its
open work to one bounded hosting-readiness follow-up. This is evidence that the
policy workflow remained reachable, not an unaided demonstration of minimal
review scope. AGENTS replaced the stale environment value with a link; whether
that makes everyday operating-summary lookup more costly was not tested.

## Round 1: source authoring

A fresh agent simplified one named paragraph in pattern-capture while preserving
meaning. The [patch](authoring-routing/source.patch) retains applicability,
evidence versus proposal, sufficiency of one supported mechanism, recurrence as
additional confidence, uncertainty and local tradeoffs. Package and whitespace
checks passed; no other file changed.

It read approximately **3,786 words** across AGENTS, clear-writing, instruction
guidance, the target skill and its validation page, plus approximately **3,400

That repeated the earlier source-catalog finding in
[discovery validation](discovery.md#consumer-and-authoring-route-trials--2-october-2026)
and motivated the round-2 section routes.

## Round 2: repeat the source edit

A fifth fresh agent received the identical paragraph-edit task in a fresh source
fixture with the revised AGENTS and README. Its edit matched the
[round-1 patch](authoring-routing/source.patch). Parent comparison again found
all meaning and certainty preserved, and package/whitespace checks passed.

The agent read AGENTS, the target skill, clear-writing and instruction guidance
in full: **2,279 words**. Excerpts added 324 words from README authoring sections,
242 from the target skill's behavior cases, 373 from clear-writing behavior cases,
and about 500 words of overlapping search output. No full README or full
validation-history read occurred. These are displayed-read counts with overlap,
not a unique-content total or a precise reduction percentage.

A broad heading/keyword search still returned short historical trial bullets,
violating the trial's exclusion. The agent reported that it did not use those
excerpts. This limits the isolation result: section routing improved, but the
run is not evidence that unnecessary history reads were eliminated. Keep this
as an execution/search-scope finding; a second round does not justify adding a
new universal instruction for every avoidable search result.

## Verification and remaining limits

The parent reviewed the actual consumer artifacts and both source diffs against
their tasks. Package validation passed for 23 entries and one collection; staged
whitespace and changed-link checks passed. Source AGENTS writing/instruction rules
were followed for these maintenance edits. Only shared routing and maintenance
instructions changed; there is no new executable helper to test.

The consumer trials demonstrate avoiding authoring on a lookup, preserving
writing/table selection for a new comparison, and preserving policy impact
review for a short decision change. The source trials preserve required editing
checks and show reduced catalog/history loading, with a remaining search-scope
failure. Counts are single-run observations, and changes in tooling/friction
reads also affect comparisons. No general word budget or reliability claim is
established.

No Markdown table render, database/runtime behavior, network operation, release,
installation update or next project phase was tested. Real Atlas and the
unrelated Python validation edit were left untouched. The remaining broad reads
in policy/definition references and source searches are recorded candidates, not
new mandatory workflows or reasons to repeat this round indefinitely.
