A design workflow selects materials from a shared collection. The storage team publishes a filesystem interface at /mnt/catalog/materials, containing material directories with maps and metadata.json. Selection reads it; a separately authorized batch indexer writes metadata. The storage team operates the mount and its upload cache. The consumer currently checks only that the directory exists. We are deciding whether the consumer should introduce its own local mirror and an HTTP materials server. Another service has offered its private storage directory as a shortcut to its published export operation.
