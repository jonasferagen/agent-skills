## Findings, misses and limits

1. No blocking defect in strict format or the installed route chain was found. Existing active four-member wording would become stale upon adding Renderer; the fixture reconciliation removed those copies. Historical migration statements were left as history.
2. The first exec call failed because the default shell process could not be created. Explicit `/bin/bash`, `login=false` worked. This was tooling friction, not a guidance route failure.
3. Reading the complete shared foundation for the initial retention question also loaded Boundaries and Overview before those sections were immediately needed. They were reused for bootstrap. Bundling the two scenario phases saved rereads but does not measure the smallest retention-only read cost.
4. Bootstrap legitimately required substantially more guidance than consultation: policy/docs/authoring routes and member checks. No diagrams, Mermaid renderer, source-release rules, upstream catalog, historical implementation or unrelated specialist skills were loaded. No known required route was missed for the work actually performed.
5. No actual nested worktree was created because Git was optional and this fixture is outside Git. Worktree access and Git landing were not exercised; a real Git scenario still needs its adopted worktree workflow. Shared main-checkout selection was reviewed as a rule, not tested against multiple Git branches. Container access remains unverified.
6. Cycle/conflict examples were reviewed in guidance, not executed as new adversarial fixtures. The shape checker establishes syntax only: it does not prove inherited truth, permissions, runtime readiness, offline enforcement, Blender availability, selected version, retention implementation or recovery capability.
7. The short edit proceeded under the local missing-owner rule and known constraints. No stale substitute was introduced. Shared-dependent changes would require restored owner access; cached context was not treated as authorization for a new decision.

Shared guidance, the original binding and temporary Recovery probe were restored. No temporary owner directory remains. The next unresolved Renderer decision is the Blender version and evidence for an offline render workflow.
