# Adopted policy

| Axis | Current fact or decision |
| --- | --- |
| Intended lifetime | Maintained local archive |
| Users and reliance | One maintainer; private reference work |
| Data | Real, irreplaceable archive documents; encrypted retained files |
| Exposure and authority | Offline operation; no external transfers |
| Compatibility | Preserve existing archive identifiers |
| Recovery | At most 24 hours of accepted additions may be lost; maintainer owns recovery |
