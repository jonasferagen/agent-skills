# Contracts task-routing trials

Synthetic fixtures and results for project-contracts 0.2.0, 3 October 2026.
Each case ran in a separate fresh evaluator context, outside the authoring
repository. A complete draft collection was copied to the fixture's
`.agents/collections/project-foundation/`; that duplicate is not retained here.
The source baseline was `634df2e`, with the contracts task-routing changes in this
revision. The fixtures' AGENTS links refer to their original installed location.
These files are evidence, not instructions for this repository.

Each directory retains its task, adopted agreement, answer and read log:

- [Read](read/answer.md): interpret the completion term.
- [Apply](apply/answer.md): assess a successful build without acceptance evidence.
- [Design](design/answer.md): propose obligations for withdrawn photograph permission
  and downstream cached packages, under facts supplied by the fixture.
- [Review](review/answer.md): assess independent requests competing for one current package.
- [Wording](wording/answer.md): change only the heading's participant name.

The evaluator prompts requested the task from AGENTS.md and context.md, confined
access to the individual fixture, prohibited installed-guidance changes and
external actions, and requested an answer plus a read log. They supplied no
expected route, finding or proposed fix. Read-log prompts explicitly asked about
missing guidance; these trials do not demonstrate spontaneous friction capture.
