# Publishing handoff — adopted revision 1

Editorial supplies a document revision to Publishing. Publishing produces a
candidate package containing the document and its attachments. Editorial accepts
it when the content matches that revision and all attachments are present.
Publishing retains accepted packages. A rejected candidate does not replace an
accepted package. Publishing reports completion after Editorial acceptance.

Each candidate records its request identifier and input revision. Repetition of
the same request returns its existing candidate. Changed input uses a new request.
