# Validation scenarios — Jonas Email Style

Use these cases when changing the skill. They describe expected behavior, not
results from an independent agent evaluation.

| Request and context | Expected outcome |
| --- | --- |
| Draft a short Norwegian first-contact question for Jonas to send | State the situation and question plainly; use a suitable greeting and sign-off. Do not add a generic closing paragraph. |
| Rewrite Jonas's reply inside an active thread | Preserve the answer and any requested action; usually begin with the substance, without adding a new greeting. |
| Shorten a long draft with three distinct questions | Keep all three questions and necessary facts while cutting filler; retain a short list if it reads better than prose. |
| Draft an English note to a technical contact | Lead with the symptom or fact, then a concise hypothesis or question in Jonas's established register. |
| Draft mail for another sender or an organizational voice | Do not apply Jonas's personal tics as a universal email style. Follow the actual sender's instructions and context. |
| The request gives a fact, relationship, or tone that differs from the old sample | Treat the request as current context; do not infer facts or overwrite the requested tone from the corpus. |

The source corpus ends before 2026-09-18 and may not reflect later changes in
Jonas's style. These scenarios have been reviewed against the skill text; no
independent behavioral evaluation or fresh mail sample has been performed.
