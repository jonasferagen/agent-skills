# Supplied brief

Known entities: organisation, agreement, service.

Retrieval questions:
1. Which agreements involve a given organisation?
2. Which service does each agreement cover?

Participant roles and relationship cardinalities have not been decided. Use a
small provisional model to reason about the questions; identify assumptions and
blocking choices rather than asking an external owner during this bounded trial.
Names and identifiers in examples must be synthetic. Do not infer an application
stack, interface, schema implementation or actual operational permission.

Produce a small database model proposal with a canonical ER view, domain glossary
and retrieval scenarios. Organize the documents so the next reader can find their
owners. This is a design exercise, not adoption for real Atlas or a runtime test.
