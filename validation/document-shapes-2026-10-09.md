## Findings and evidence

Work-records 1.0.0 supplies reusable assignment, evidence and disposition methods.
A brief can be a bounded plan item or separate commission; reports, studies and
transfers are uses of records; a worklog collects dated records. Concrete shapes
and templates belong to the project or its adopted framework. No subtype registry
replaces the removed templates. The method remains independently usable.

Removed the five template files and their live routes. Preserved their semantic
obligations in the method: reachable required inputs, explicit exclusions,
completion evidence, revision identity, comparable conditions, retained candidate
basis, transfer identity, evidence limits and actual deciding authority. Kept
`work-record/v1` and its optional Kind/Workflow fields compatible. Removed only
the test that asserted the now-retired shipped templates exist; placeholder
rejection, vocabulary agreement and all parser behavior tests remain.

The [standalone consumer trial](document-shapes-2026-10-09/standalone/trial.md)
started in a new agent with no forked conversation, using a fixture outside the
source repository and its installed skill route. It produced a bounded commission
without requiring templates, a framework, optional metadata or a checker. Missing
PNG files and exact revisions remain prerequisites; no numerical threshold,
comparison result or acceptance was invented. Ravi performs the comparison and
Mei selects. The reviewer inspected the actual output, not just the agent summary.
The retained read log identifies every reported source/guidance read and its
approximate words. All reported method reads were relevant; none required source

The downstream coordinated task also exercised an existing brief/report pair,

catalog discovery. Host ambient metadata remained available; work-records had no
ambient catalog entry. Reads are agent-reported rather than a complete host tool

paragraph were reviewed after the trial; the final package gate covers them, but
no second independent trial is claimed. The output already preserves the supplied
input and authority obligations.

No actual icon comparison was performed. Existing consumers, records and pins are
not migrated by this source change. No release tag or remote publication is part
of this work. No claim of lower total reading time follows from deleting templates.

## Disposition

import this committed revision and own concrete work-definition and record shapes.

without rewriting historical records or their assessed basis.

template. Concrete shape selection belongs to the consuming convention; this
skill's extension boundary now names that owner. Further rule capture is unnecessary.
