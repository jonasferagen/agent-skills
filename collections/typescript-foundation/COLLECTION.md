# TypeScript foundation

Version: 0.1.1

Use this collection for TypeScript implementation and Node command-line tooling.
Start with repository instructions, actual runtime and existing tooling. Install
the complete collection; choose members by the operation being changed.

| Task | Guidance |
| --- | --- |
| Shape TypeScript operations, values, ports, naming or module boundaries | [TypeScript design](skills/typescript-design/SKILL.md) |
| Change TypeScript types, narrowing, generics, module syntax or enforcement | [TypeScript patterns](skills/typescript-patterns/SKILL.md) |
| Shape a TypeScript operation with type-boundary decisions | Read both TypeScript members and relevant references |
| Write or review a Node process wrapper, CLI check or harness | [Node patterns](skills/node-patterns/SKILL.md); add TypeScript members only for TypeScript decisions |
| Install, update or check this collection | [Installation](references/installation.md) |

Node guidance also applies to JavaScript command-line scripts. A plain JavaScript
browser rendering change does not select TypeScript rules or Node child-process
patterns. Do not infer TypeScript adoption from this installation. A focused type
fix need not restructure classes; design tasks use the member's house style within
repository constraints and its conflict handling.

Application operations, services and test authoring retain their project routes.
A Node test harness may need both runtime and verification guidance. Report a
missing required route with its consequence. Ordinary work needs no installation
guide or source catalog; install does not choose a framework or add dependencies.
